# Template inclusi

Qui non ci sono più template: tutti i siti supportati hanno un plugin Python nostro (`picfinder/plugins/`).

I template `.etmpl` restano supportati. Chi ne ha uno lo aggiunge da solo:

- trascina il file `.etmpl` nella finestra dell'app, oppure
- **File → Apri cartella dei template** e copialo lì, oppure
- **Strumenti → Editor dei template…** per scriverne uno nuovo.

Se per lo stesso sito c'è un plugin Python con `PREFERRED = True`, il plugin passa davanti.
